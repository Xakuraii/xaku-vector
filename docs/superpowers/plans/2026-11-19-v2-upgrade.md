# XakuVector v2.0.0 Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade XakuVector to version 2.0.0 with sample feature removal, clean emoji-to-icon transition, metric card text wrap fix, and a fluid continuous zoom & pan preview navigation engine.

**Architecture:** 
- State management: Extend preview transform state in `useImageConverter` (or custom viewport hook) to track continuous `zoom` (0.25 - 8.0) and `pan` (`{ x, y }`).
- Interaction handlers: Listen to wheel, pointer/mouse, and touch events on the preview viewport to support mouse wheel zoom, touch pinch-to-zoom, right-click desktop dragging, and mobile touch panning. Synchronize split preview panes so comparisons stay aligned.
- Metric UI: Normalize font sizing and apply `whitespace-nowrap` on `FileMetrics.tsx` to prevent unit wrapping on tight column layouts.

**Tech Stack:** React 19, TypeScript, Tailwind CSS v4, Lucide React, Vitest, Testing Library.

**Spec:** `docs/superpowers/specs/2026-11-19-v2-upgrade-design.md`

## Global Constraints
- Target version: `2.0.0`
- Zero server dependencies: 100% client-side operation
- Zero regressions in existing size-optimizer and svg-generator services
- All Vitest integration and unit tests must pass

## Review Focus
- Rapid mouse wheel zooming must clamp within bounds (0.25x to 8x) without NaN or extreme jumps.
- Right-click mouse drag must not trigger browser context menu when panning.
- Mobile single-finger pan and two-finger pinch-to-zoom must not cause native page scrolling conflicts (`touch-action: none`).
- Metric card 1 ("Generated .SVG Size") must never wrap `"KB"` onto a second line regardless of viewport width.
- Tests asserting version strings and sample buttons must be cleanly updated.
